# YSS 本机工作台 · Tesla Light

个人本机多工程工作空间。主导航依次为工作台、产品与工程、Spec、执行记录、设置。项目页保留 `/projects` 入口，Home 地图导入与本机目录绑定集中在产品与工程页。工程详情提供 Spec 关联、工程维护和研发关联。设置提供本机诊断、备份恢复与程序重启。

主色 #3E6AE1，背景 #F7F8FA，表面 #FFFFFF，标题 #171A20，正文 #25272B，次要文本 #62666C，边框 #E4E6EB。状态同时显示名称与图形。采用系统字体，字体、Markdown 与 Mermaid 资源随应用内嵌。

桌面顶栏 56px，侧栏 224px，标签页 40px。表格行高基线 40px，含项目副行的 Spec 行 52px。按钮、输入与单选控件统一为 34px，窄屏为 44px。行内字段与复选框按中心线对齐，纵向表单保留 6px 标签间距。控件圆角 8px，区域容器圆角 12px。正文 13px，辅助 11–12px，页面标题 24px。

单选使用共享 Reka Select，菜单与触发器左侧对齐，间距 4px，接近窗口边界时翻转或避让。菜单宽度跟随触发器，并限制在可视区域。弹窗内的菜单挂载到所属原生 dialog，支持方向键、Enter、Escape 与焦点返回。

Spec 详情按规格、待确认事项、生命周期、关联资源、研发关联、运行 Pi Agent、变更历史、设置组织。标题下显示工程和来源路径，首屏显示下一步与阻塞，个人标记按需展开，保存按钮在编辑时出现。问题、生命周期和资源使用表格，问题背景及个人资源编辑按需展开。问题区域低于 820px 时转换为堆叠行。标签、阶段、问题类别及文档章节由 URL 保留。提醒直接定位对应类别或问题，来源刷新保留阅读位置。已解决事项在全部范围中按需显示，Spec 确认状态独立展示整份规格的确认条件。列表、看板与收藏视图共享内容状态和提醒筛选。

个人标记、问题答复、阶段说明使用独立编辑草稿，自动保存到本机工作台数据目录。编辑中保留当前输入，恢复列表可读取其他会话的草稿。并发修改提供开始编辑时、当前输入、最新记录的逐字段选择。保存期间新增的输入保留为草稿。列表和历史按需读取，来源变化通过本机更新流局部刷新。

Pi 在独立 worktree 中运行，可选带入指定未提交文件。执行详情呈现宿主有效设置、会话和执行日志。文件接收展示运行起点、原工程当前内容与运行结果，逐文件选择，冲突文件在核对后选中。接收预览显示目标原工程的分支和 HEAD，审阅令牌绑定该次成果与目标基线，版本变化后重新选择文件。确认版本比较先展示变化文件，再按需读取文本差异，图片由用户加载前后对照，当前图片按差异摘要核对原字节。历史 HTML 原型可在隔离窗口中阅读，文件可按原字节下载。旧确认记录在当前产物完全匹配时可补存快照，并展示实际保存时间。GitHub、GitLab 研发关联展示外部读取状态和时间。

低于 1200px 合并工作台侧栏，低于 900px 详情纵向排列，低于 720px 导航横排滚动。新增表单控件在窄屏至少 44px，文本输入为 16px。表格、生命周期和文件对照保留独立滚动。可见标签、键盘焦点、原生 modal dialog、状态播报与减少动画偏好沿用现有约定。原始组件许可证见 provenance。

工作台首页按内容待办、执行与待处理、Spec 推进组织。内容待办和推进范围按类别切换，最近访问与最近操作并排列表。工程和执行记录使用可搜索表格，Home 条目可逐行核对和绑定目录。工程维护与设置按任务分组，诊断、执行结果和研发关联优先呈现摘要、状态和读取时间，原始数据按需查看。

执行记录总表一行对应一次任务，按最近更新时间排序。请求历史在工具栏右侧独立查看，待核对请求在总表上方处理。Pi 执行详情在工程和整体状态下默认打开会话。用户要求右对齐，Pi 答复与工具步骤左对齐。命令在结束后可以展开输出和退出码，业务答复卡片在同一个会话内提交并显示保存结果。会话位于底部时跟随新消息，向上阅读或加载历史时保持阅读位置。Codex 与其他作业默认打开执行日志，活动按时间、内容摘要和单步结果展示，全文和原始事件按需读取。本次产物与文件变更在相邻页签中读取。续接后的旧记录保留当轮内容，并链接到最新执行与成果。

恢复运行后，可在工作区差异中核对旧工程路径与当前登记路径、分支及 HEAD，明确确认后更新绑定。更新后清空接收选择并重新读取差异，文件接收仍需重新审阅。
