# YSS 本机工作台 · 浅色毛玻璃

个人本机多工程工作空间。普通页面共用 168px 左侧导航栏。窗口低于 880px 时默认显示 62px 图标栏，宽度达到 720px 时可以手动收起或展开，选择在切换页面时保留。顶部展示当前工程范围并可展开切换，中段是工作台、产品与工程、规格管理、AI Agent，底部是桌面设置（桌面端）、本机设置、本机用户和侧栏开关。当前导航项以浅蓝底和深蓝文字标记。工程菜单在展开时向下打开，在图标栏中向右打开，展示最近更新的 6 个启用工程，并提供全部工程入口。工程详情显示当前工程，工作台汇总全部工程。执行记录从工作台的「执行与待处理」进入，执行页仍标记在工作台下。Home 地图导入与本机目录绑定集中在产品与工程页。工程详情提供 Spec 关联、工程维护和研发关联。设置提供本机诊断、备份恢复与程序重启。

默认使用浅色毛玻璃。背景以淡暖橙和冷蓝渐变铺底，导航和弹层使用半透明背景与模糊，内容面板和卡片采用不同透明度。Pi 工作区共用材质，表格固定列和全屏成果阅读保留实色底。浏览器不支持背景模糊时使用实色表面，减少透明度、增强对比度和强制颜色模式下关闭渐变与模糊。

主色 #3E6AE1，标题 #171A20，正文 #25272B，次要文本 #62666C，基础边框 #E4E6EB。状态同时显示名称与图形。采用系统字体，字体、Markdown 与 Mermaid 资源随应用内嵌。

导航栏展开时横向展示图标与名称，收起时保留图标与可访问名称。导航元件的触控区域至少 44px，短窗口允许栏内滚动。右侧页面标题和操作随文档滚动。标签页 40px。表格行高基线 40px，含项目副行的 Spec 行 52px。页内按钮、输入与单选控件统一为 34px，窄屏为 44px。行内字段与复选框按中心线对齐，纵向表单保留 6px 标签间距。控件圆角 8px，区域容器圆角 12px。正文 13px，辅助 11–12px，页面标题 24px。

页面共用 shadcn-vue New York v4 组件。单选菜单与触发器左侧对齐，间距 4px，接近窗口边界时翻转或避让。菜单宽度跟随触发器，并限制在可视区域。弹层和嵌套菜单由 Reka 管理，支持方向键、Enter、Escape 与关闭后返回触发点。编辑中的关闭动作遵守保存状态与草稿确认。

Spec 详情按规格、待确认事项、生命周期、关联资源、研发关联、运行 Pi Agent、变更历史、设置组织。标题下显示工程和来源路径。首屏进展卡使用一条进度条展示本次目标的总体进度，按已核实项和应核实项计算。目标已验收时显示满值与验收状态，进度无法计算时显示待核实。卡片同时展示下一步、阻塞和最近核实时间，各阶段详情可在生命周期页签查看。保存按钮在编辑关联设置或资源时出现。问题、生命周期和资源使用表格，问题背景及个人资源编辑按需展开。问题区域低于 820px 时转换为堆叠行。标签、阶段、问题类别及文档章节由 URL 保留。提醒直接定位对应类别或问题，来源刷新保留阅读位置。已解决事项在全部范围中按需显示，Spec 确认状态独立展示整份规格的确认条件。Spec 列表统一展示自动进度，收藏视图保存筛选和排序。

关联设置与个人资源、问题答复、阶段说明使用编辑草稿，自动保存到本机工作台数据目录。编辑中保留当前输入，恢复列表可读取其他会话的草稿。并发修改提供开始编辑时、当前输入、最新记录的逐字段选择。保存期间新增的输入保留为草稿。列表和历史按需读取，来源变化通过本机更新流局部刷新。

AI Agent 打开当前可用规格的 Pi 工作区。没有当前规格时，优先上次打开的可用工作区，再按规格最近访问和更新时间选取。工作区左栏可切换规格。Pi 在独立 worktree 中运行，可选带入指定未提交文件。执行详情呈现宿主有效设置、会话和执行日志。文件接收展示运行起点、原工程当前内容与运行结果，逐文件选择，冲突文件在核对后选中。接收预览显示目标原工程的分支和 HEAD，审阅令牌绑定该次成果与目标基线，版本变化后重新选择文件。确认版本比较先展示变化文件，再按需读取文本差异，图片由用户加载前后对照，当前图片按差异摘要核对原字节。历史 HTML 原型可在隔离窗口中阅读，文件可按原字节下载。旧确认记录在当前产物完全匹配时可补存快照，并展示实际保存时间。GitHub、GitLab 研发关联展示外部读取状态和时间。

低于 900px 详情纵向排列。低于 720px 时保持左侧图标栏，右侧内容缩小页边距并按空间换行。窄屏 Spec 列表保留搜索和已选条件，筛选项按需展开。主要表单控件在窄屏至少 44px，文本输入为 16px。宽表格、生命周期和文件对照在各自区域滚动，表格滚动区提供可聚焦的名称。页签可用方向键浏览、Enter 切换，与页面定位有关的页签保留在 URL。加载、空结果和错误使用共享反馈组件，支持减少动画偏好。组件来源与许可证见 provenance。

工作台首页的页头显示本机工作台、工程范围、最近读取时间和页面操作。内容按待办、执行与待处理、Spec 推进排列。待办和推进每个页签最多展示 5 条 Spec，待办角标统计事项总数，推进角标统计规格总数，两区均可进入保留当前筛选的规格列表。执行与待处理、最近更新的规格和最近操作各展示最多 5 条。执行与待处理、最近更新的规格提供对应列表入口。待办和推进的页签与表格共用面板，页签随可用宽度分行，窄屏点按区域至少 44px。内容待办和执行均已读为空时共用一个状态面板，可用宽度达到 680px 时并排。有待处理内容时保留对应的列表。最近更新的规格和最近操作共用一个面板，时间放在标题下方。内容区宽度达到 1160px 时，该面板与 Spec 推进顶端对齐并位于右栏，较窄时排在主任务区下方。Spec 推进按面板自身宽度调整表格和页签。工程和执行记录使用可搜索表格，Home 条目可逐行核对和绑定目录。工程维护与设置按任务分组，诊断、执行结果和研发关联优先呈现摘要、状态和读取时间，原始数据按需查看。

首次读取按表格、详情、表单和卡片形状保留版面，慢请求显示 Skeleton。页面按路由加载，切页期间保留当前内容，慢切换时在右侧操作区顶边显示不定进度条。页面资源加载失败时可重新打开目标页面。首页从页头刷新，其他普通页从本机用户菜单刷新当前页面。需要后台核验的页面在核验发布后更新结果，失败时保留可用的上次结果。刷新与查询保留仍适用的结果和阅读位置，慢请求在表格可视范围内显示 Spinner。追加在列表末尾反馈，提交在发起按钮上显示处理状态。短请求不闪现加载动效。

按钮反馈、页签切换和抽屉分别以 110、180、240 毫秒为基线。菜单从触发位置淡入，抽屉沿所在边缘进出。Pi 会话列表在桌面直接贴左，页头历史按钮用于收起侧栏，或在窄屏打开抽屉。收起时保留当前筛选，收起的侧栏暂时退出键盘导航。运行设置从输入区左下角打开。执行成果用铺满可视区的弹窗展示，标题、关闭按钮和接收操作固定，内容在窗内滚动。减少动态效果模式提供相同的操作和静态反馈。

执行记录总表一行对应一次任务，按最近更新时间排序。请求历史在工具栏右侧独立查看，待核对请求在总表上方处理。Pi 执行详情在工程和整体状态下默认打开会话。用户要求右对齐，Pi 答复与工具步骤左对齐。命令在结束后可以展开输出和退出码，业务答复卡片在同一个会话内提交并显示保存结果。会话位于底部时跟随新消息，向上阅读或加载历史时保持阅读位置。Codex 与其他作业默认打开执行日志，活动按时间、内容摘要和单步结果展示，全文和原始事件按需读取。本次产物与文件变更在相邻页签中读取。续接后的旧记录保留当轮内容，并链接到最新执行与成果。

恢复运行后，可在工作区差异中核对旧工程路径与当前登记路径、分支及 HEAD，明确确认后更新绑定。更新后清空接收选择并重新读取差异，文件接收仍需重新审阅。
