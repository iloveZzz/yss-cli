# YSS Spec 工作台 · Tesla Light

个人本机多项目工作空间，主导航为工作台、项目、Spec 与任务。项目页发现候选后手工关联；Spec 详情同时呈现只读正文与个人标记，资源和历史单独切换。列表与看板复用服务端查询；Spec／任务可切换，按六种状态或阶段分组，支持收藏视图。详情的五个标签依次为规格与标记、任务、生命周期、关联资源、变更历史。八阶段节点以个人记录显示，不推断顺序完成。

主色 #3E6AE1；背景 #F7F8FA；表面 #FFFFFF；标题 #171A20；正文 #25272B；次要文本 #62666C；边框 #E4E6EB。状态同时使用名称与图形，不只依赖颜色。

桌面顶栏 56px、侧栏 224px、标签页 40px、控件 28px。表格单行基线 40px，含项目副行的 Spec 行 52px。圆角 8px，区域容器 12px。系统字体，无远程字体。正文 13px，辅助 11–12px，页标题 24px。

低于 1200px 合并工作台栏；低于 900px 详情纵向排列；低于 720px 导航横排、控件至少 40px、表格和看板横向滚动。表单标签、错误提示、可见焦点、原生 modal dialog、未保存离开提醒随功能提供。减少动画偏好生效。看板保留空列和完整计数，每列按需展开；拖动与“移动到…”菜单共用窄字段动作。原生对话框负责焦点约束，关闭任务时回到原任务入口；保存中的后续输入保留为未保存草稿。

原始依赖组件许可证见 provenance；token 与应用布局已按工作台设计替换，starter 默认页面未保留。
