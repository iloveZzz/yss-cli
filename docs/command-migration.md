# Cobra 命令迁移记录

基线：c10acc98f1d0ef9002a341bdc5cc822a4edc11dc（2.4.0）。执行环境 Go 1.27.1 darwin/arm64、Node 24.21.0、Git 2.56.0。原工作区仅设计与计划未跟踪；实现位于隔离分支 codex/cobra-command-layer。此记录是兼容清单，不是运行时命令注册表或发布回执。

## 消费者与共同合同

- cmd/yss/main.go、Run/RunWithTerminal、Invoke/ServeMCP、check.runCheck、tools/helpdocs、tools/smoke/main.mjs 走同一命令入口。
- 模板只读核对 scripts/lib/native-context.mjs（context check --root/--json 等）、edit-hook.mjs（check）、lifecycle-progression.mjs（目标）、reading-view-bundle.mjs（reading），及 yss-product-lifecycle/references/daily-delivery.md（route/verify-daily）。保留命令中间参数、JSON envelope 和退出码；不修改模板。
- 公共参数为 help/json/version/human/diagnostics；项目 root 不传播到程序升级。布尔仅小写 true/false；semantic、scaffold、upgrade 拒绝重复，其余按原后值覆盖。--kind 和 skills list --details 的值相关范围继续由原约束控制。
- 顶层 init/attach/sync/diff/doctor/recover/rollback/version/capabilities 不接位置参数；check 接一个或多个文件，explain 接术语。skills/assets 的 ensure 标识可多项，resolve 按原数量检查；治理 arg0 由 ArgumentKeys 声明，不能任意扩展。
- tracker 父命令默认 status（仅显式 status 接 fetch）；update 默认 plan。git 必须子命令，policy 无 set 时查询，branch/hooks/release 必须三级动作。其余治理父命令原样转 status，可能返回原 UNPORTED；不把原拒绝改成功。
- 副作用按具体动作：项目/资源默认计划（init 默认应用）；apply 消费保存计划；recover/rollback 无 apply 查询；reading render、runtime 写动作、archive pack/unpack、bundle export、trace --html 和 tracker link --apply 为本地写。Git 写、Tracker sync apply、upgrade/update 保留原计划、摘要和确认；status --fetch、Tracker sync plan 和 upgrade check 涉及联网。
- 无法枚举用户仓外脚本；发现当前清单外的真实兼容用法须登记，不能以框架默认行为覆盖。帮助及补全始终离线、无业务副作用。
