YSS CLI 2.8.1 以已发布的 CLI 2.8.0 和模板 v4.8.0 为基线，增加 IDEA 插件所需的预演、确认及核查接口。现役 Profile 为 Spec 与 Backend，JSON envelope 协议保持 v1。

## 本版变化

- 新增 IDEA 集成能力声明与项目只读检查，支持识别安装状态及结果核查。
- AI 安装可生成绑定 CLI 可执行文件、Bundle、目标与确认摘要的计划；应用时验证确认摘要和现场，普通 CLI 计划保持兼容。
- DDD/MVC 脚手架支持只读计划、确认应用和结果核查；生成目标已存在时拒绝覆盖。
- 保留 2.8.0 的技能选择及依赖规则，不自动修改已有项目或全局 CLI。
