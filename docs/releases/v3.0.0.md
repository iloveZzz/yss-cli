YSS CLI 3.0.0 支持模板 v5.0.0 的 `matt-spec-v1` 非技术 Spec 工作流：按需研究和产品设计，在所选 Issue tracker 整理规格，技术与实现交由下游处理。

## 本版变化

- 新建或接管 Spec 默认安装最小 governed 工作流，并核验固定来源与受管政策。Context、Plan、阶段 checkpoint 和独立交接包不再是初始化要求；研究与设计技能按需补装。
- Spec tracker 支持 `local-markdown`、GitHub 和 GitLab，远程目标须明确配置。实际规格发布由技能调用连接器或已配置工具完成；配置成功不代表发布成功或获得业务批准。
- 旧 governed Spec 升入新工作流须人工迁移，sync 和安装方式转换不会代做迁移；普通 skills 安装仍按既有安装合同同步。新 Spec 明确拒绝旧阶段、交接及实施命令，Backend 保留自身合同与校验。
- 修复普通工程 attach 为新 Spec 时强制校验旧 Context 格式的问题，保留既有 `CONTEXT.md` 内容与权限；其他身份和 Profile 继续执行各自校验。
- 保留注册表 v2 的技能退役支持及历史 v1 兼容，校验别名目标、冲突与循环；同步和补装继续保护用户文件，删除须符合适用升级规则。
