### 主要变更

- 新增 WorkBuddy 项目技能文件分发和就绪查询。普通文件投影纳入现有安装、同步、来源锁、冲突保护与恢复；WorkBuddy 桌面行为仍待实机验收。
- 将 Matt skills v1.3.1 的方法改进接入现有 YSS 流程：明确业务 Ticket 与实施切片的边界，统一当前复核政策，按实际信号复盘并复用修复证据。
- 实施准备核对批准范围、工程基线与测试入口；并行工作明确写域、源码观测隔离与汇合次序，在同一最终候选上验收。
- 修复模板 checkpoint 检查缺少原生 CLI 准备依赖的问题。未整体替换 Matt 上游锁，也未新增自动批准或调度机制。

### 升级

macOS ARM64 已受管安装可使用 `yss upgrade --to 2.7.0` 升级程序；自定义工具根需显式传入 `--tool-root`。升级程序不会自动修改项目模板。

在目标项目上先生成并审阅同步计划，再应用同一文件；下面的路径需替换为实际绝对路径，计划输出文件应放在项目外且尚不存在：

```sh
yss version --json
yss doctor --root /path/to/project --json
yss sync --root /path/to/project --plan --out /path/outside-project/sync-4.7.0.json --json
# 审阅变更、冲突和保留项后执行：
yss sync --root /path/to/project --apply --plan-file /path/outside-project/sync-4.7.0.json --json
yss doctor --root /path/to/project --json
```

遇到冲突、来源不匹配或用户修改时按计划处理，不强制覆盖。真实项目仍需按自身业务测试入口验收。Windows x64 可核对 `SHA256SUMS` 与 `build-only-checksums.json` 后解压使用。

两平台归档、来源与资格绑定见 `SHA256SUMS`、`checksums.json`、`build-only-checksums.json`、原生 receipt 和发行门禁文件。
