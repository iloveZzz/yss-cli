YSS CLI 2.8.3 修复默认 skills 初始化及后续补装缺少技能引用资料的问题。Spec 和 Backend 现从固定模板安装声明的引用和必要依赖，并继续保护用户文件。

## 本版变化

- 默认 skills 安装与技能补装包含各 Profile 声明的 `.template-source`、`.template-spec` 引用资料及必要依赖；治理实例仍可显式选择 governed。
- 校验技能资源的固定来源和受管摘要，迁移、同步与补装保留文件冲突保护。
- 私有 Bundle 存储 v2 将安装集合初始文件也放入按摘要复用的对象池；逻辑 Bundle 内容、身份及公开快照格式不因私有编码变化而改变。
- 新版读取器继续支持并校验历史私有存储 v1；旧读取器不能读取私有存储 v2，旧二进制仍保留自己的 v1 归档。程序回滚按现有升级事务恢复旧二进制及安装文档。

## 下载校验与边界

两平台归档为 `yss_2.8.3_darwin_arm64.tar.gz` 和 `yss_2.8.3_windows_amd64.zip`；归档及证据摘要见 `SHA256SUMS` 和相应清单。Windows x64 归档仅构建打包，不具备在线升级资格。本说明记录发布前验收；发布后 Mac 公开在线升级、安装身份、回滚、恢复和用户文件保护需由同一生产提交的 verify-public 工作流另行验证。

模板公开技能仓的只读导出检查缺少 `setup-yss-harness`，该仓库尚未同步。模板 Node 22 工具全套检查有 1 项因未配置 antd 工具链而跳过；该项不能视为通过，详见模板发行说明。
