YSS CLI 2.6.0 正式版固定关联模板 v4.6.5，现役 Profile 为 Spec 与 Backend，JSON envelope 与协议保持 v1。

### 主要变更

- 原生支持 Spec 四阶段门禁：Plan 批准、Spec 基线批准、实施准入、交付验收；阶段结果绑定当前资产、真实用户决定和验证证据。
- 新增 `yss lifecycle decision plan/apply/migrate-plan`，通过保存计划登记阶段结果、更新 checkpoint，并显式迁移旧阶段记录。缺少可信证据时保留缺口；普通模板同步不迁移产品状态。
- 实施准入统一核验当前 Spec、业务 Ticket、架构、API、切片合同及适用复核；阶段审查绑定已验证候选、实际执行和当前范围。
- 补齐阶段交付与 Spec / Backend 交接校验，保留历史来源 Profile 和原始签署政策；固定 Bundle 包含更新后的 Harness 指引。

- 修复 Windows 阶段事务提交时重复读取自身独占锁导致的失败；只读校验继续守卫锁文件内容。

### 固定来源

- CLI：`b4844f90adf3730687da1ea877d4a4ef62796b2c`
- Spec / Backend 模板：`v4.6.5`，`e1d6b3889f94de3fc1a5e935c11a03ff3b648ddc`
- 发布构建：Go 1.27.1，`CGO_ENABLED=0`。模板 tag、提交、版本与内嵌资产摘要经过一致性核验。

### 验证与发行范围

- Linux：全量 Go 测试、覆盖率门禁、格式、vet、构建、黑盒冒烟、完整生成物校验，以及 Go / Node 脚手架逐字节对拍。
- macOS ARM64：真实原生定向回归、最终固定二进制的 version 与两个 Profile inspect、隔离程序安装五项（plan 只读、apply、rollback、recover、用户文件保护）；资格范围为 `local-platform-program-install`，稳定包 `stableReady=true`。
- Windows x64：真实原生定向 Go 回归；发行 ZIP 的最终执行器为交叉构建，包保持 `stableReady=false`、`nativeRuntimeVerified=false`，不具备在线升级资格。
- 本次范围不包含全部旧实例迁移、强制中断恢复矩阵或完整模板 / 插件发行验收。
