YSS CLI 2.8.2 更新 Spec 与 Backend 初始化使用的模板快照，补齐治理实例引用的政策、流程和技能资源，并加强补装与用户文件保护。

## 本版变化

- Spec 治理实例包含入口政策和流程术语资产；Backend 对齐用户决定、跨端交接和 Plan 迁移合同。
- 治理技能已安装而条件资源缺失时支持补装；受管资源被用户删除时保留冲突保护，避免静默覆盖。
- 更新独立技能与治理研究边界，补齐竞品研究验证的传递依赖，并同步技能投影。
- 现役 Profile 为 Spec 与 Backend；原生 CLI 与其固定 Bundle 一并分发。

## 下载校验与边界

两平台归档为 `yss_2.8.2_darwin_arm64.tar.gz` 和 `yss_2.8.2_windows_amd64.zip`，归档及证据摘要见 `SHA256SUMS` 和相应清单。Windows 归档仅构建打包，不具备在线升级资格。

本说明记录发布前验收；公开下载后的 Mac 在线升级、安装身份、回滚、恢复和用户文件保护需由同一生产提交的 verify-public 工作流另行验证。模板公开技能仓的只读导出检查缺少 `setup-yss-harness`，该仓库尚未同步；详见模板发行说明。
