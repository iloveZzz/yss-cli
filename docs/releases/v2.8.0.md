YSS CLI 2.8.0 固定关联模板 v4.8.0，现役 Profile 为 Spec 与 Backend，JSON envelope 与协议保持 v1。

## 本版变化

- Spec 默认独立技能安装包含八个入口：yss-product-lifecycle、grilling、yss-research、domain-modeling、to-spec、i-have-adhd、code-review 和 implement。生命周期路由可帮助按任务选择适用技能，治理仍按需启用。
- 治理技能安装选择会纳入条件成立的必需技能依赖，并与安装校验保持一致；缺失依赖按既有机制报告，不通过查询自动安装。来源锁、摘要、权限及宿主投影校验继续生效。
- 更新模板来源、生成的帮助和版本文档，移除已退役的基线导出入口。已有项目和本机全局 CLI 不会因发布自动升级或迁移。

## 下载校验与边界

两平台归档为 yss_2.8.0_darwin_arm64.tar.gz 和 yss_2.8.0_windows_amd64.zip，固定到同一生产提交。七个 payload 的摘要见第八个附件 SHA256SUMS；Mac 稳定包与 Windows build-only 的资格分别保存在随包清单和共同证据中。

本说明记录发布前验收。发布后的公开下载和 Mac 在线安装、身份、回滚、恢复及用户文件保护须由同一生产提交的 verify-public 工作流另行验证。未覆盖真实业务模型交付、宿主自动发现和 WorkBuddy 桌面实机验收。旧执行器可能拒绝新版来源锁，应先校验新包并使用新执行器引导隔离安装。
