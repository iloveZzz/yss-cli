YSS CLI 2.7.5 固定关联模板 v4.7.4，现役 Profile 为 Spec 与 Backend，JSON envelope 与协议保持 v1。

## 本版变化

- 修复默认独立 `skills` 初始化后，`skills resolve` 因缺少本地治理注册表而误报 `blocked` 的问题。Spec / Backend 的 canonical 与 WorkBuddy 查询可正常返回 `ready`；现有项目无需重新初始化、同步或迁移。
- 仅 metadata5 且 `installation=skills` 跳过本地治理注册表检查；注册信息始终来自固定 Bundle。技能锁、来源与快照、文件内容和权限、投影及运行时保护保留；治理安装、旧身份与非法身份仍按原规则校验。
- 条件依赖未安装仍返回 `missing`，查询不补装。参数、身份 schema 与退出码语义不变，按 `result.status` 判断就绪状态。
