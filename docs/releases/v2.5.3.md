YSS CLI 2.5.3 修复 Tracker、程序恢复、文件写入与 MCP 的可靠性问题，固定消费模板 v4.6.4，现役 Profile 为 Spec 与 Backend。

### 变更与兼容
- Tracker 保存计划升级至 v2：绑定 API 来源和 Ticket 范围，严格重建合法改动；旧 v1 计划返回 `PLAN`，需重新执行 `tracker sync --plan --out <新文件>`。JSON envelope 和协议继续为 v1。
- Tracker 使用原始字节/权限守卫，逐项复核并只增删五态标签，保留无关标签。部分失败保留实际远端副作用、本地事务回执及原错误码；`remote_state=unknown` 时先查询对账，不自动重放。
- program-update 未发布准备在完整校验后封存，可解除准备阶段取消造成的阻塞；支持旧完整计划无准备头，未知或冲突材料保留并拒绝。
- 运行对象完整写入、校验与同步后原子发布，不覆盖已有对象；归档安全打开，及时拒绝 FIFO、链接、目录及超限输入。
- MCP 在空闲输入及调用期间响应取消，关闭输入并收尾读取协程，避免迟到输出。
- 当前版本、模板和 Profile 文档自动核验，internal 覆盖率 CI 下限提升至 30%。
