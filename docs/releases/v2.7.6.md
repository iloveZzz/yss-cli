YSS CLI 2.7.6 固定关联模板 v4.7.6，现役 Profile 为 Spec 与 Backend，JSON envelope 与协议保持 v1。

## 本版变化

- Spec 治理安装默认安装八项入口技能，阶段资源按需补齐对应专业技能；独立 skills 安装默认保留 implement、code-review。--full 保留所选安装方式，并安装该方式的完整资源。
- Spec 的 doctor 分别报告文件、已安装技能及工作流状态；初始化与同步完成时核验技能、声明的 Claude/WorkBuddy 投影、来源、内容和权限。技能就绪不代表工作流已经验收，workflow 保持 not-evaluated。运行时声明丢失、来源锁异常、资源或投影漂移继续阻断。
- 初始化回执及人类提示使用实际 installation；帮助、tutorial 与接入说明区分独立技能和治理模式。继承 2.7.5 的独立技能 resolve 修复。
- HTTP 失败诊断增加经过格式限制的限流数字头及请求 ID，不记录响应正文、凭据或任意响应头，不增加自动重试。
