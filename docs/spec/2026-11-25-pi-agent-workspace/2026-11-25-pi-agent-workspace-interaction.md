## 查看原型

页面右上方的「原型场景」提供会话与成果、新建会话、模型恢复、等待业务答复和接收冲突五个模拟场景。原型使用「工作台加载体验」示例 Spec，默认展示已完成一轮的「补齐原型加载反馈」。 [在浏览器打开当前原型](../../../prototypes/2026-11-25-pi-agent-workspace/dist/index.html)

当前版本可评审现有会话流程及冲突核对。待处理筛选、连续活动分组、差异选行返工、已接收后撤销及事务异常接收属于新增首版验收，下一轮队列属于下一批。下方「评审场景」中的验收编号对应当前模拟所覆盖的操作。 [首版与下一批验收](2026-11-25-pi-agent-workspace-spec.md#验收)

从源码运行时，在 YSS CLI 仓根执行以下命令。使用原型自身的锁文件。

```sh
cd prototypes/2026-11-25-pi-agent-workspace
pnpm install --frozen-lockfile
pnpm dev
```

执行 `pnpm build` 可重新生成本地单文件入口 `dist/index.html`。

## 页面组织

| 位置 | 内容与操作 |
| --- | --- |
| 桌面左侧 | 窄图标栏提供会话历史、来源 Spec、执行历史和当前成果入口。旁边的会话栏显示当前 Spec 的 Pi 会话，可折叠，可新建和切换。 |
| 顶部 | 显示当前会话，提供运行设置和右上摘要操作。窄屏从顶部打开历史或成果抽屉。 |
| 中部会话 | 逐轮显示任务、Pi 答复、工具步骤和业务问题。工具详情默认折叠，操作与结果在所属轮次下可查。 |
| 底部输入 | 输入任务后发送，活动轮中可准备草稿，并通过「停止运行」结束当前轮。设置区负责本机模型、工程和本轮命令授权。 |
| 右上会话摘要 | 展示最新轮的变更、本轮执行和来源入口。桌面展开或收起摘要，点击文件变更进入成果抽屉。 |
| 成果抽屉 | 展示有明确轮次归属的可读产物、文件变更和接收状态。接收动作紧邻选中文件及目标工程。 |

页面按参考图使用黑白灰和简洁分隔，对话与底部输入同宽居中。命令与差异使用等宽字，状态有文字反馈。窄屏优先保留对话与输入，历史、成果和设置按需打开。

## 操作与反馈

| 操作 | 能看到的结果 | 规则 |
| --- | --- | --- |
| 新建会话，打开运行设置 | 主工程已选，允许加入其他工程。按工程填要带入的相对路径，可选择模型和当轮命令权限。空输入及不满足条件的提交保留已有选择。 | FR-01、FR-02 |
| 选择模型或运行「重新检测」 | 点击输入区模型名，从本机 Pi 候选搜索或筛选供应商。新会话可恢复 Pi 默认模型，续接可沿用会话模型或为下一轮改选。连接测试在运行设置中显示状态和结果。 | FR-02、FR-05 |
| 删除会话记录 | 在左侧对应条目打开确认框。取消后保留记录并回到删除按钮。确认成功后移除该会话及各轮工作台记录，保留工程文件和隔离工作区。 | FR-01 |
| 发送与观察 | 提交受理后显示用户消息、运行状态和逐步出现的 Pi 内容。滚到较早消息时可手动回到最新；可在对话内展开工具项。 | FR-03 |
| 停止与续接 | 停止请求显示等待，终态显示实际结果。原会话具备续接条件后可以发送下一轮，已留存内容仍可读。 | FR-03、FR-05 |
| 回答 Agent 的业务问题 | 在该轮的问题卡片选择推荐项或自填并提交。保存成功后显示答复并继续当前轮。提交未受理且问题仍待答时可重试，已失效时保留填写供参考。 | FR-04 |
| 查看或接收成果 | 切换产物与变更。核对差异后逐文件勾选并接收。差异过期时清除失效的选择。仍有冲突时查看原工程当前内容并明确采用隔离结果，再勾选且提交。重开成果抽屉时可核对同一轮的版本与接收记录。 | FR-06 |

## 评审场景

| 原型场景 | 操作路径 | 核对 |
| --- | --- | --- |
| 会话与成果 `#default` | 展开已完成会话的工具步骤与成果，切换一条历史会话，回到原会话发送续接。运行中可停止，之后可再续接。 | AC-01、AC-04、AC-05、AC-07 |
| 新建会话 `#new` | 选择范围及模型，查看当轮命令授权，输入任务并发送。 | AC-02、AC-03、AC-04 |
| 模型恢复 `#readiness` | 查看发送受阻和保留的输入。重新检测后主动测试，观察模拟的方舟套餐错误。改选其他模型或重检后再次测试。 | AC-03 |
| 等待业务答复 `#question` | 选择推荐项或填写自定义答复，提交并查看保存后的原轮结果。 | AC-06 |
| 接收冲突 `#conflict` | 打开文件差异，按提示重新核对并勾选。接收部分文件后关闭并重开成果抽屉，核对原工程版本、已接收标记及仍待审阅的文件。 | AC-07、AC-08、AC-15 |

## 模拟边界

演示中的对话、命令输出、模型检查和接收结果均为浏览器模拟。继续对话时可以回看旧轮消息、工具和日志，成果抽屉展示最新可审阅轮。真实 Pi、平台限制、浏览器重连与历史分页、原工作区可续接性、历史产物快照缺失、答复保存失败、实际 Git 隔离、多工程部分接收和真实并发文件变化由生产验收覆盖。差异选行、返工撤销与队列按主规格对应场景评审。
